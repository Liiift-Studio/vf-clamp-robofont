vf-clamp

Generate restricted variable fonts from named instance ranges.

Usage

  1. Go to Extensions > Generate Restricted VFs…
  2. Click Select Font… and choose a variable .ttf or .otf file.
  3. Select one or more named instances from the list.
  4. Edit the Output Family Name if needed (auto-filled from your selection).
  5. Choose a Format (TTF, OTF, WOFF, WOFF2).
  6. Optionally choose a different Output Folder (defaults to the font's folder).
  7. Click Generate.

How It Works

The extension uses fontTools.varLib.instancer to compute the axis hull (min/max per axis) of the selected instances, then restricts the variable font to exactly that range. The name table (family name, PostScript name) is updated to reflect the purchased range so the file self-identifies correctly.

Requirements

  • RoboFont 4 or later
  • Python 3 (bundled with RoboFont)
  • fontTools (bundled with RoboFont)
